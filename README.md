# Runory

Перший фронтенд-прототип Runory — сервісу зрозумілого аналізу бігових тренувань із Garmin.

## Уже працює

- охайна адаптивна сторінка Runory;
- вибір файлу кнопкою та drag-and-drop;
- перевірка розширення `.fit`;
- стан підготовки з прогресом;
- екран базового аналізу після завантаження;
- локальне читання реальних дистанції, часу, темпу, пульсу, каденсу та набору висоти з FIT-файлу.

Результати зчитуються прямо у браузері: файл не надсилається на сервер і не зберігається.

## Структура

- `index.html` — сторінка застосунку;
- `src/main.js` — поведінка інтерфейсу та стани завантаження;
- `src/styles.css` — зовнішній вигляд;
- `src/services/fitParser.js` — FIT-парсер для базових показників.

## Наступний етап

Додати графік темпу й пульсу, спліти по кілометрах і детальніший висновок про тренування. Після цього логічний наступний крок — зберігати тренування в історії користувача.

## Запуск на комп’ютері

Проєкт підготовлено для Vite. Після встановлення Node.js відкрийте папку проєкту в терміналі та виконайте:

```bash
npm install
npm run dev
```
